// capabilities

What it can do.

🤖

Scenario Testing

TestPilot acts like a real user — clicks, fills forms, navigates, verifies results. No selectors to write. No scripts to maintain. Just describe the scenario.

🔐

Security Testing

Test that User A can't see User B's data. Checks URL manipulation, IDOR, session persistence, role escalation — the vulnerabilities no-code builders miss.

👥

Multi-Role Testing BETA

Run scenarios across multiple users simultaneously. Dispatcher assigns a job. Contractor bids. Admin approves. All in one test run.

💬

Interactive Mode BETA

Chat with your app through TestPilot. "Go to Clientes. Create Ivan Fernandez." Natural language control over a live browser session.

// embeddable widget

One line. A “Test” button
inside your own app.

Paste a single tag and a floating “Test” button appears in your app — so you and your team can run TestPilot on the live page, no dashboard round-trip. It runs on your own Claude key, and your secret key never touches the browser.

<script src="https://testpilotapp.dev/embed.js" data-tp-token="pk_live_…" defer></script>
🔑
Your key never touches the browser Connect your Anthropic key once. It's stored encrypted (AES-256-GCM) on our server — the embed only carries a public token. Revoke anytime.
💳
Bring your own key Every test runs on your key — you pay Anthropic directly. No markup, and Anthropic's API doesn't train on your data.
🤫
Nothing captured silently Your login token is read only if a user opts into “test as logged-in user” — first-party, over HTTPS, for that one run. Never in the URL, referrer, or history.
👁️
We test your app — we don't harvest it We store only what your report needs — the learned page map + run screenshots — scoped to your account. Never sold or shared, and deletable.
